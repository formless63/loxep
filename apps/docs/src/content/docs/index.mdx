Loxep is an open-source, self-hosted platform being designed around three connected ideas: **market intelligence**, **business operations**, and **financial truth**.

The first useful vertical slice centers on eBay monitoring: watchlists and explicit listings first, followed by searches, sellers, prices, availability, restocks, and historical observations. The architecture is deliberately broader so those capabilities can grow into multichannel commerce, inventory, service work, billing, shipping, purchasing, accounting, tax support, media/documents, and reporting without becoming a collection of disconnected tools.

## Current foundation

The current implementation plan is intentionally pragmatic:

```text
minimal deployment

loxep                    # TanStack Start + Graphile Worker
postgres-timescale
```

The same Loxep image supports `LOXEP_MODE=all|web|worker`, so the default stays simple while background workers can later scale onto separate processes or hosts.

Media uses a `local`/generic-`s3` abstraction. Local filesystem storage requires no additional service; **RustFS** is the initial recommended/tested optional self-hosted S3 companion and can be added as a separate service in the same Compose project. Local-to-S3 migration is a supported application workflow rather than a future manual rewrite.

The application UI will use **Kiranism's TanStack Start dashboard** as its initial shell/donor, preserving useful responsive layout, shadcn/Base UI patterns, and multi-theme system while replacing demo data, auth/backend assumptions, unnecessary state/dependencies, and stale version pins with Loxep's own architecture.

Better Auth owns application identity, sessions, OIDC/magic-link login, and deployment roles. Loxep owns domain/resource permissions such as access to a specific marketplace/store connection.
