# Loxep

**Loxep** is an open-source, self-hosted platform for marketplace intelligence, multichannel commerce operations, services, billing, inventory, and financial visibility.

The project begins with eBay monitoring and market intelligence, but is intentionally designed as a modular system that can grow into broader commerce and small-business operations without forcing unrelated workflows into a single abstraction.

The name combines **loxodrome** and **ephemeris**: navigation and observation over time.

## Status

Loxep is currently in the planning and architecture phase. Documentation is being developed first so that product scope, domain boundaries, and architectural decisions remain explicit as agent-assisted implementation accelerates.

## Documentation

Project documentation will live in `apps/docs` and be published with Astro Starlight on GitHub Pages.
